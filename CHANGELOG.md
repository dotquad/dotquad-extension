# Changelog

## [Unreleased]

### Added

- Popup: your IP, where it appears to be, its network and a VPN, proxy, Tor or hosting badge; "Grade this site" for the current tab, with the grade, its five sections and the network and country it's hosted in.
- "Is this link safe?" on a link's right-click menu, and "Look up on Dotquad" for selected IP addresses, domains, ASNs and CIDR ranges (CIDR math runs in the browser). Results open in Chrome's side panel or Firefox's sidebar.
- "Grade on the icon", off until turned on in Settings, which then asks for the `tabs` permission.
- An optional API key in Settings, so lookups run under the key's plan.
- Chrome, Edge and Firefox builds from one codebase (Manifest V3).
